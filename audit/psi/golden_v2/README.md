# Golden fixture: alpha Cen AB linear-kinematics chain (joint validation)

A minimal, self-contained test vector for cross-validating independent
implementations of the alpha Centauri AB intercept kinematics. If your code
reproduces `expected_outputs.json` from `golden_inputs.json` within the stated
tolerances, our kinematic chains agree end-to-end (astrometry conversion,
frame rotation, linear propagation, crossing solve, and the v_inf/beta
curves) and any remaining disagreement is attributable to *inputs* alone, with
code ruled out.

## Contents

| File | Role |
|---|---|
| `golden_inputs.json` | One agreed astrometric state + unit/epoch conventions + 5 test epochs |
| `expected_outputs.json` | T_cross (three time conventions) and v_inf/beta at the 5 epochs, with tolerances |
| `check_golden.py` | Standalone checker (Python 3.8+, stdlib only): recomputes and asserts |

## The agreed state

Akeson et al. 2021 (AJ 162, 14) barycenter solution for alpha Cen AB, taken
at its **native epoch J2019.5** and used epoch-consistently: position
(RA 219.85892215 deg, Dec -60.83163195 deg), orbital parallax
750.81 +/- 0.38 mas, mu_alpha* = -3639.95 +/- 0.42 mas/yr,
mu_delta = +700.40 +/- 0.17 mas/yr. Position, parallax, PM, and RV all belong
to the same instant, and the velocity vector is built on the J2019.5
direction basis. The proper-motion convention is mu_alpha* (cos-dec factor
included); the barycentric solution matters (an individual star's
instantaneous proper motion differs by up to ~5 km/s of orbital wobble).

The RV is the **kinematic-frame** (true line-of-sight) barycenter velocity
-22.3182 +/- 0.0034 km/s: Akeson's spectroscopic gamma
V0 = -22.3796 +/- 0.0020 km/s plus the gravitational-redshift zero-point
correction of Kervella, Thevenin & Lovis 2017 (A&A 598, L7). That paper quotes
the bias as Delta v_GRS(alpha Cen A) = -61.4 +/- 2.7 m/s; the applied
zero-point correction is -Delta v_GRS = +61.4 m/s. The sigma is the quadrature
of the two. These are catalog
central values plus a declared frame correction, chosen as a *fixture* and
clearly labeled: it is neither a new measurement nor a statement that this
catalog is preferred.

Sigma labels: the parallax and PM sigmas above are Akeson catalog formal
errors. The 0.10 km/s working RV sigma used in dispersion studies is an
*adopted absolute-accuracy allowance* that appears in no catalog; it plays no
role in this deterministic fixture.

## Model and conventions (each declared)

Heliocentric mean-ecliptic J2000 frame; obliquity rotation R_x(23.43928 deg)
applied to the ICRS Cartesian state, with the rotation sense
y_ecl = cos(eps) y_ICRS + sin(eps) z_ICRS and
z_ecl = -sin(eps) y_ICRS + cos(eps) z_ICRS (as implemented in the checker);
constant space velocity (linear motion):

    r(T) = r0 + v T
    T_cross  = -z0 / v_z                    [yr]   ecliptic-plane crossing
    v_inf(T) = |r0 + v T| / T               [km/s] required straight-line coast speed
    beta(T)  = asin( z(T) / |r(T)| )        [deg]  ecliptic latitude of intercept point

- **State epoch = J2019.5** (Akeson native). The propagation clock T (and the
  5 test epochs) run in years from this instant; v_inf(T) uses the same T.
- **Mission time origin = departure epoch 2029.0.** Reported alongside the
  state-clock value: `T_cross_from_departure_yr = T_cross_yr - 9.5` and
  `crossing_date_AD = 2019.5 + T_cross_yr`.
- **RV frame = kinematic** (see above). Substituting the observed gamma
  -22.3796 km/s moves the crossing ~298.9 yr earlier (the RV lever is
  ~4,870 yr per km/s); the fixture pins the kinematic value.
- Unit constants are pinned in `golden_inputs.json` (`pc_km`, `ly_km`, Julian
  `year_s`, `kms_per_masyr_pc` = 4.74047e-3). Use them verbatim: at the quoted
  tolerances, convention drift (e.g., a different obliquity or km/s-per-mas/yr
  factor) is distinguishable from a genuine model discrepancy.

## Headline expected values

- T_cross = 79,765.875 yr on the state clock = 79,756.375 yr from departure
  2029.0; crossing date AD 81,785.375.
- Crossing distance 6.427805 ly; v_inf at crossing 24.15829 km/s.
- beta passes through zero between the 79,000 and 80,000 yr epochs, by
  construction of T_cross.

Full-precision values and per-quantity tolerances (all T_cross conventions to
0.02 yr, v_inf to 1e-4 km/s, beta to 1e-4 deg, distance to 1e-6 ly) are in
`expected_outputs.json`.

## Running

    python3 check_golden.py            # prints PASS/FAIL per value, exit 0 on pass
    python3 check_golden.py --write    # regenerate expected_outputs.json

## Provenance and validation

Expected outputs were generated by `check_golden.py` (a from-scratch stdlib
implementation) and cross-checked against a second, separately written
implementation of the same chain; the two
agree to machine precision (within 1 ulp) on T_cross, crossing distance, and
v_inf, and the rounded values match the memo's primary values.

Scope: the fixture validates the *linear* kinematic chain only. Neglected
deterministic terms are bounded elsewhere; the largest is Proxima Centauri's
gravitational pull on the AB barycenter (+7.1 yr in T_cross; 105.6 AU of
track deflection at crossing, cross-track 79.3 AU = 3.1% of the 2,600 AU
success radius; both evaluated at the 79,372 yr working-state crossing,
and moving to this fixture's 79,766 yr crossing changes the deflection by
under 2 AU), followed by light-time, galactic tide, and barycentric
wobble. Input uncertainty dominates the crossing-time budget: the program
band on the crossing date is +/-400-800 yr against catalog and RV-frame
systematics.
